## Generic per-ROM event record — 2026-09-23

The current worktree appends a 1,548-byte `WorldEventSaveV1` to the SaveBlock1 sector-5 tail in each ROM's own save image. It stores 4,096 regional flags, 4,096 trainer-defeat bits and 256 variables behind a versioned header and CRC. No world ID is baked into the record: the launcher must keep regional images under immutable catalog world IDs, so another ROM can reuse the format while retaining independent quest state. Invalid nonempty records reject a save before flash writes; an all-zero tail initializes on load. Rejected logical saves use a separate screen path and do not run physical sector repair, even when an old damage bit is set. Link save and trade callers stop on a blocked operation.

The runtime event adapter reserves the same flag, variable and trainer-ID windows in every additional ROM. Each ROM's regional image gives those local IDs independent values, while the shared player record remains common. Typed script flag/variable commands can distinguish the overlapping `0x8000` special vars from regional flags. Coordinate events have only a numeric trigger, so `0x8000–0x8FFF` is assigned to regional flags there; future content must use other IDs for scratch-variable coordinate triggers. Hidden-item IDs use explicit 13-bit legacy, Johto and additional-ROM ranges so a regional flag cannot overwrite the adjacent packed item and quantity fields. The currently staged Cormoria coordinate events use `VAR_TEMP_*`, with no overlapping scratch-variable triggers.

An independent read-only review scanned all 1,011 current host coordinate events and 256 authenticated Cormoria-stage coordinate events; none uses the overlapping scratch-variable IDs. It found no concrete issue with the final flag-priority rule. Future content registration must keep that restriction visible to authors.

The event adapter test run passed six `World` tests, one hidden-item marker test, 95 `Johto` tests and 130 `Cloud` tests (with eight existing `TO_DO`). A focused ARM coordinate-trigger test passed again after the final `0x8000` precedence correction. A GNU assembler probe confirmed the packed hidden-item data preserves item and quantity for legacy, Johto and additional-ROM IDs. The 19-test Python event-ID, catalog and map registration run passed with one environment skip. These checks exercise the generic adapter, not a live Cormoria map or cross-ROM travel.
